Begriff 1

Race Condition

Zwei oder mehr Threads greifen gleichzeitig auf eine gemeinsame Ressource zu und ändern sie. Das Ergebnis hängt davon ab, wer zuerst zugreift, und ist möglicherweise falsch.

Bei uns: Ressource = counter. Ergebnis 1 015 201, 1 023 518 oder 1 031 171 statt 2 000 000.

Begriff 2

Kritischer Abschnitt

Der Teil des Codes, der auf die gemeinsame Ressource zugreift. Dort darf immer nur ein Thread gleichzeitig sein.

In C 
int counter = 0;   // global
void* increment_counter(…) {
  for (…)
    counter++;}
auf der CPU
In Assembler
  1. mov eax, [counter]
  2. add eax, 1
  3. mov [counter], eax

Warum kritisch? counter ist global: Beide Threads lesen und schreiben dieselbe Variable, und aus einer C-Zeile werden drei Befehle.

Globale Variablen und Thread-Funktion

int counter = 0;pthread_mutex_t mutex; void* increment_counter(void* arg) {    for (int i = 0; i < 1000000; i++) {        pthread_mutex_lock(&mutex);        counter++;        pthread_mutex_unlock(&mutex);    }    return NULL;}

main

int main() {    pthread_mutex_init(&mutex, NULL);    pthread_t thread1, thread2;    pthread_create(&thread1, NULL, increment_counter, NULL);    pthread_create(&thread2, NULL, increment_counter, NULL);    pthread_join(thread1, NULL);    pthread_join(thread2, NULL);    pthread_mutex_destroy(&mutex);    printf("Final counter value: %d\n", counter);}
pthread_mutex_init

Mutex einrichten.
Danach ist er frei.

pthread_mutex_lock

Abschließen. Schon gesperrt? Dann hier warten.

pthread_mutex_unlock

Aufschließen. Ein Wartender darf weiter.

pthread_mutex_destroy

Mutex aufräumen, wenn ihn niemand mehr braucht.

Kurzform bei der Deklaration

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;

Ersetzt pthread_mutex_init(&mutex, NULL). Der Mutex ist sofort eingerichtet und frei.

Race Condition

Mehrere Threads greifen gleichzeitig auf gemeinsame Daten zu und ändern sie. Das Ergebnis hängt davon ab, wer zuerst zugreift, und kann falsch sein.

Mutex

lock vor dem kritischen Abschnitt, unlock danach. Immer nur ein Thread ist drin, alle anderen warten.

Der Preis

Warten kostet Zeit. Halte den kritischen Abschnitt deshalb so klein wie möglich.
